# DECADEnts
DECADEnts spec + two characters each decade. One biological age, one psychological age. The amount they differ from each other can scale with their complexity (meaning the least fleshed out ones can be hardly differentiated from each other and only exist as separate characters for technical purposes like a more flexible humor delivery system like the 1920s, while the most fleshed out characters can be very different from each other to convey more about the decade itself like the 2020s). They'll be named: The roaring 20s (two characters representing the decade), the 30s...
