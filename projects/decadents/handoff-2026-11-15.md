## 6. Pitfalls met in this run

1. **Memory guard.** The session's low-memory guard killed a HunyuanImage batch once and forbids restarting it unasked. Run HunyuanImage when Idi has said so, and stop ComfyUI the moment a batch ends.
2. **Thumbnails lie.** jep reported "sealed 6 of 6" from 600 px thumbnails; a blind critic at full size found 2. Counts come from a blind agent at full size.
3. **Negations leak.** "No dinosaurs" drew dinosaurs in September. Every September prompt still ends in "no face, no skin"; rewrite positively for new work.
4. **Naming a person draws a person.** "A soldier whose face is hidden" got a face in 14 of 14. "The head is a ..." seals.
5. **Puppets grow faces** on Z-Image-Turbo (4 of 4).
6. **Usage limits and a safety filter cost three agents.** Keep agents few and briefs tight; have them write the file early. Reading the `gpu-unlock-ada` repository's content got an agent stopped: use `repo_census.py` (metadata and keyword counts only).
7. **Guards.** Bash lines that mention a `.git` folder path are refused. Edit and Write to the main vault are refused from a background worktree: write in the tools folder and `cp`, or use a small Python script (pattern: `card_log3.py`, `append_answers.py`).
8. **The v0.45 archive needs 7-Zip** (`/c/ProgramData/chocolatey/tools/7z.exe`); the Python extractor fails on it.
9. **Licence wording.** Say the H3-Image limit the way section 4 does; jep overstated it once as a flat bar.
