# No Boilerplate - Obsidian for Learning III: Projects

Part 3 of 3. Before: [[No Boilerplate - Obsidian for Learning II Process]].

## What it says

- [0:40] The one job of any task system: answer **"What should I be doing right now?"**
- [0:50] The layers are ordered simple to complex "allowing you to drop off when you think the complexity is right for you."
- Layer 1 [1:00] Daily note. Write today's list before starting, then pick the one task that "would kind of win the day." He calls this habit "90% of productivity."
- Layer 2 [2:40] Project files. A note tagged `project` with a due date. Inside a project the list is ordered by sequence, first step first. Inside a day the list is ordered by importance.
- Layer 3 [4:05] Next actions (from GTD). A table with one row per project showing only its first unchecked step, sorted by due date. A table of whole projects "just lets you see what large projects you have to do and maybe panic."
- Layer 4 [6:10] Start date. A project stays off the next-actions table until its start date. "Only the things that can be started."
- Layer 5 [7:10] State. A Kanban board from a `state` property, using the Kanban view built into Bases.
- Layer 6 [8:10] Contexts. Mental modes, since every task now lives on one device. His five, after the "Eudaimonia Machine" in Cal Newport's *Deep Work*: Chamber (deep work, no web), Library (light writing, web allowed), Office (open task-hopping), Salon (messages), Theater (no tasks).
- [12:10] "You probably don't need everything I have talked about today." "A system of last resort." "Beware of the seductive optimizations of toxic productivity." "As simple as possible, but no simpler."
