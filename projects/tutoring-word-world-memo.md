## Options

**A. Keep it as the centerpiece.** Run session 6 around Word World again, sequential format, D first.
For: the game was interrupted, never tested; its hooks (avatar, building, named bots) sit past the few minutes it got.
Against: spends the scarcest resource, a session slot, on the one option the girls already declined; the 6-word pool and production layer stay unaddressed.

**B. Rebuild toward their taste.** Faster pace, louder feedback, same-keyboard co-op, larger word pool, then re-present.
For: the co-op insight ("אני החכמה ואתה החזק") is real and unbuilt.
Against: two more build weekends on one data point; the taste evidence comes from a session where the girls chose console games over everything, which predicts nothing about a rebuilt v10. Building into the same void is the pattern the parts registry names.

**C. Shelve as centerpiece, keep on the menu.** (recommended)
Lesson engine returns to what has reception: Game Lab 2D, dictation with the counter, word pool grown live. Word World stays installed as one option D can pick in her solo slot. If she picks it, run the five observation asks. If it is not picked in two sessions, shelve fully; the file and the W in the jar stay.
For: the constraints that matter are engine-independent and the 2D game already holds them; costs zero build time; a fair test still happens if D wants it.
Against: the 3D build's design ideas (ladder, silver cards, garden) go untested unless she opts in.
