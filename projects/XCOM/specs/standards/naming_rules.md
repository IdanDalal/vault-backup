# Character Naming Rules & Constraints

## 1. The Syllable Suffix Rule
*   **Format**: `[Rank ID]) [First] '[Nickname]' [Last] - ([Syllables]) [ShortCallsign].md`
*   **Constraint**: The suffix number `(N)` MUST match the syllable count of the **ShortCallsign**.
*   **Purpose**: Efficient vocal callouts.

## 2. The "Crew/VIP" Exception
*   **Target**: Rows 181-200.
*   **Name**: "1 ONE", "2 TWO", etc.
*   **Visuals**: Generic Black Suit (The "Black Underwear" layer).
*   **Role**: Non-combat personnel.

## 3. The Alliteration Rule (The "Triple-Letter" Standard)
*   **Rule**: First Name, Nickname, and Last Name MUST start with the same letter.
    *   *Example*: `Solomon 'Stranger' Stillbrow`.
*   **Exceptions (The "Heroes")**:
    1.  **Kazimir 'The 11th' Pavlovich**: The Star. "The 11th" = Campaign count.
    2.  **Jane 'The Eternal' Kelly**: Canon character, permanent 2IC.
    3.  **Dancis 'Knightfather' Joyeuse**: Tribute to the modding community/ChristopherOdd.
*   **Constraint**: All 177 *other* soldiers must follow the alliteration rule.

## 4. Original Characters vs. "Cosplay"
*   **Rule**: Soldiers are **Original Characters**. They are NOT the pop-culture icons whose outfits they wear.
*   *Example*: Even if a soldier wears the "John Rambo" mod outfit, their name CANNOT be "John Rambo". It must be an original name (e.g., `Randal 'Rampage' Raines`) wearing that gear.

## 5. The "Callsign" Variable
*   **Definition**: The word you say in your head to refer to the character.
*   **Constraint**: Must be 1-2 syllables.
*   **Origin**: Can be the First Name, Last Name, or Nickname (shortened if necessary).
*   **Output Requirement**: Every generated name must specify its **ShortCallsign**.

## 6. Faction Themes
*   **Skirmishers**:
    *   **Theme**: Primordial, Nature, Violence.
    *   **Constraint**: BLACKLIST modern/materialistic/tech concepts (No "Laser", "Cyber", "Gear").
    *   **Examples**: `Boulder`, `Roar`, `Scourge`.
*   **Reapers**: *Implied stealth/survival/hunter themes (from existing examples like Midnight, Void).*
*   **Templars**: *Implied religious/psionic/knightly themes (from Prophet, Demigod).*
