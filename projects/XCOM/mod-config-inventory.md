# Mod config inventory: what can be configured

Scope: the 1,111 active mods on 2026-09-14. 1,013 ship config files; 403 of those only override base-game inis (data tweaks, no switches of their own) and are left out of the table; 610 ship their own options ini (`XCom<Mod>.ini`) and are listed. Columns: mod, options ini files, distinct keys (settings) across them, S9 = Odd Season 9 Campaign Tweaks already overrides that ini, SX = Odd SX Gameplay Tweaks does (disabled, reference only), sample of key names. Big key counts on weapon packs are stat tables per weapon, editable but rarely worth it. Where a change goes: `jepFixes\Config\<same ini name>` with the exact `[Section]` header and only the changed lines (loads last, survives updates).

Total: 610 configurable mods. Grouped by Steam tag, sorted by key count.

## Config decisions, worked cases (2026-09-14)

Where every change goes: `XComGame\Mods\jepFixes\Config\<ini>` (loads last, survives Workshop updates; mirrored in `projects/XCOM/jepFixes/`).

1. Choose My Class (1467643380), file `XComChooseMyClass.ini`, key `NumClassChoices`. Mod default 3, Odd S9 tweaks set 5 and `bUseMyClass=false`. DONE: jepFixes sets 30 (Idi's last-campaign value). `-1` shows every available class.
2. Sitreps. Two levers. (a) `[XComGame.X2SitRep_DefaultSitReps] -SitReps="Name"` in `XComGameData.ini` unregisters a mod-added sitrep (Odd S9 and SX use it; base-game sitreps are code-created and do not respond). (b) Multiple Sitreps REDUX (3739636065), file `XCom_Sitrep_Categories_REDUX.ini`, `+BlockedSitReps="Name"`: global block list honoured when rolling, any sitrep, base game included, plus repair of already generated missions. Use (b). Lightning Strike = template `LightningStrike`, from Covert Infiltration (2567230730). 121 sitrep templates exist in this list (23 base game, 98 modded); names below. Also in that mod: `SitrepAmount=3` guaranteed sitreps per mission, `MaxRerollAttempts=200`; Odd S9/SX leave it at defaults.
3. PCS loot. Vanilla chain: enemy timed loot and vulture loot roll `PCSDropsEarly/Mid/Late`, which mix `PCSDropsBasic` (Common), `PCSDropsRare`, `PCSDropsEpic`. The three item tables are redefined by Odd S9 tweaks, Long War 2 Abilities and Cut Content Psionics (they add their own PCS), so editing them collides. The three mix tables are untouched by every mod. Option A: drop the Common tier only, redefine `PCSDropsEarly` (Rare 20, Epic 10) and `PCSDropsMid` (Rare 60, Epic 20); `Late` has no Common already. Option B: no PCS drops at all, redefine the six timed and vulture tables without their PCS entry (six long lines copied exactly). Recommendation A: keeps Rare and Epic for min-max, three short lines.
