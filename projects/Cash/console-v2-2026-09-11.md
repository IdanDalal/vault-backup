## Design rules applied, with sources

- Stephen Few, *Information Dashboard Design* (bullet graph, one screen per view, data-ink, no dual axes, sparklines). Rules known from the book; the course PDF was too large to fetch today.
- DataCamp, "Effective Dashboard Design" tutorial (datacamp.com/tutorial/dashboard-design-tutorial): Z-pattern, inverted pyramid (status → trends → detail), "color as a signal, not decoration", pair every KPI with a target, filters in one row with a reset, safe defaults, last-updated stamp, tuck rare controls behind "More", 10-second rule.
- Bach et al., "Dashboard Design Patterns", IEEE VIS 2022 (arxiv 2205.00757): content patterns (data, meta information, visual representation, interaction) and composition patterns (layout, structure via tabs, screenspace, colour).
- Claude's dataviz skill (bundled): thin marks, 2 px surface gaps, hover layer by default, categorical hues in fixed order, diverging = two hues + neutral middle (used for the drift and P&L treemap colouring), text stays in ink tokens with a coloured mark beside it, table view for every chart.
- DataCamp's "Dashboard Design Concepts" course page: only the chapter outline is public (structure, visual analytics, key measurements, taxonomies, checklist); nothing more specific was recoverable.
- Past vault HTML mined by an agent: per-section hue indirection (`--hue`) from `o-parent-brief.html`, conic `@property` ring from Kid Studio, pointer-capture splitter idea → CSS `resize` grips, tinted card top-border from `emergent-system.html`.

## v2.2, the notebook's conventions applied (same night)

Ask (Idi): learn "style / preferences / standards" from `D:\work\vault\IMDb_EDA.ipynb` ("The Director's Compass", Kaggle, 2025) and apply them. The 951 KB file is 29 cells; 95% is Plotly output JSON, so a script stripped it to 41 KB of markdown + code which jep read whole. No agents were needed.

What the notebook does, distilled:
- Every section: **Claim → Evidence → Interpretation → *Next:***; chart titles state the conclusion ("Insight: …", "Sanity Check: …", "Market Context: …").
- A `pv()` receipt box after every step: black, yellow left border, the dynamic numbers highlighted.
- One dark chrome for everything: `dark()` helper, black ground, IMDb yellow accent, `sty()` tables with centred headers, zebra, hover, thousands separators, K/M abbreviations.
- Annotated charts: shaded norm bands and tails with callout boxes, dotted reference lines, % labels on bars, caveats above the plot, rich hover with context.
- Colour by meaning: RdYlGn for value, a fixed qualitative palette held across subplots, four named archetypes with fixed colours.
- Analytic moves: distribution first with a median; sanity checks with stated thresholds; a composite score from percentile ranks with explicit weights (65/35); median splits into a named 2×2; r and p stated; a radar fingerprint per group; a top-N shortlist with tie-breakers; a companion table under every chart; an actionable list at the end.
- Register: a named framework, a decision-maker persona, "The X" archetypes.

Applied to the console (functions untouched, Core untouched, 15 tests pass):
- **Findings card** on Overview, "The Pool Compass · findings": 5 findings (Allocation, Performance, Health & archetypes, Costs & execution, Ownership), each Claim / Evidence / Interpretation / *Next:*, every number computed from the ledger on every render. Interpretations cite only rules that exist (Money.md's $2,400 order floor, ONE ZERO's $24 or 0.30% fee).
- **Receipt boxes** (gold left border) on Overview, Analysis, Ledger, Export: what the data holds right now.
- **Insight subtitles** on Holdings map, Drift, Timeline, Slippage, Compass, Fingerprints, Health, Drift distribution, phrased as conclusions.
- **Position health** = 0.65 × on-target percentile + 0.35 × unrealized-% percentile, the notebook's 65/35 weighting; **archetypes** by median split: The Anchors (on target, gaining), The Runners (off target, gaining), The Sleepers (on target, losing), The Watchlist (off target, losing). Tags on company cards, in the drawer and in the Lab (`SC`, preset "health").
- **The Pool Compass** scatter: x = |drift|, y = unrealized % (or value), orb area = value, colour = tier, median lines, shaded Anchors quadrant, quadrant labels, r stated with n = 19 and the caveat that a p-value would overclaim.
- **Tier fingerprints** radar (Weight, On target, P&L, Fee efficiency, Health; median percentile per tier, largest drawn first) with its companion table.
- **Health shortlist** table, ranked with tie-breakers (value, then |drift|), health coloured on RdYlGn.
- **Drift distribution** histogram, 0.5-pt bins on RdYlGn, % labels, median line, shaded ±0.5 tolerance band with a callout.
- **RdYlGn** now colours the treemap's drift and P&L modes (red → gold → green, gold = on target).
- **Timeline callout** for the plan day (transactions, net $) with a shaded band and a dotted max line.
- Tables: centred headers, K/M abbreviation helper.
