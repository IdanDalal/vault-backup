Verdict: borrow 5 render-reliability methods, never install. First scouted repo with working code for our worst failure (long renders dying partway): resumable segment manifests, browser recycling, failure taxonomy, missing-frame retry. Capture path poor for kc-engine 4K on Windows. Source: WebFetch only (raw files, GitHub API); jep re-checked stars/licence/dates via the API and the recycle constant verbatim.

Facts: write HTML, render MP4; Puppeteer headless Chrome seeks and captures each frame, FFmpeg encodes; agent-facing (9 skills, MCP server, Claude Code plugin). 78,586 stars, 7,231 forks, created 2026-03-10, pushed 2026-11-04, v0.9.10, 238 open issues, HeyGen-backed with field data in PR bodies. Apache-2.0, TypeScript, Node 22+, 15 packages. Local render free, no account (docs/faq.mdx); HeyGen media/cloud need login; Lambda needs AWS. Telemetry ON by default (`npx hyperframes telemetry disable`). Capture: beginFrame only on Linux headless-shell; Windows = Page.captureScreenshot; Windows CI = 1080p smoke render only, producer tests skipped (.github/workflows/windows-render.yml).

1. Segment manifest + resume (packages/producer/src/services/render/segmentPlan.ts, segmentManifest.ts): DEFAULT_SEGMENT_FRAMES = 3000, closed-GOP encoder per segment, concat-copy join; manifest renders/.hf-segments/<planHash>/segments.json written atomically (temp + rename); planHash = SHA-256 (16 hex) over composition, CLI version, fps, size, codec, preset, CRF, pix fmt, GPU/CPU encoder, motion blur; reuse a segment only if hash matches, file exists, byte count matches, probed frame count = end - start; any doubt = re-capture ("the cost of reusing a bad one is a silently wrong video"). Concrete design for scout item 6. Opt-in (HF_SEGMENTED_CAPTURE=true); default held for a 40-min soak test not run as of 09-19 (PR #4115). Value high, effort medium, conf high on design.
2. Browser recycle every 3 segments (segmentRecycle.ts, verified): DEFAULT_SEGMENT_BROWSER_RECYCLE = 3, "~3 x 3000 frames keeps a session under the 10k-frame band (spec §2.5)"; retry only target loss (/target closed/, /detached frame/, /session closed/); encoder/authoring errors not retried. Field data PR #4108: Chrome "Target closed" failures 0.7 % -> 39 % above 100k frames. KC 4K died at frame 11,580 in one session, just past their band (inference, low-medium: ours was context lost + fence wait). Cheapest test: restart Edge every N frames per worker. Value high, effort low-med.
3. Failure taxonomy (packages/engine/src/services/captureFailure.ts): cancelled, transient_browser, protocol_timeout, memory_exhaustion, verification, authoring, io; each fatal or retryable. Add webgl_context_lost (readFinish: fence wait failed); render.ts:173-184 treats all as fatal today. Value med, effort low.
4. Missing-frame retry (renderOrchestrator.ts executeDiskCaptureWithAdaptiveRetry): missing = absent or <= 8 bytes; retry missing ranges only, halve workers each time, require forward progress; MAX_TRANSIENT_CAPTURE_RETRIES = 1; stall after 300 s without a new frame (FIRST_FRAME_STALL_MS). Ours: requeue the failed worker's 8-frame chunk. Pairs with 1.
5. WebGL context release (packages/engine/src/services/webglRelease.ts): tracks every webgl/webgl2 context, calls WEBGL_lose_context.loseContext() when its clip ends. Our prior for the context loss = GPU memory pressure: check Scene.dispose frees render targets/textures; log GPU memory per 1,000 frames. Value med, effort low, conf med.
6. Seam gate (.claude/skills/motion-doctrine/references/seam-gate.md, scripts/seam-gate.mjs): ledger.json row per cut (exit/entry axis + direction); measured from element rects: exits still moving, entries not from rest, direction matches plan, entry speed ~ exit speed, one side visible per frame, carrying object continuous within 12 px centre / 5 % size at cut +-1 frame. window.__kc.boxes supplies rects. New class (cut continuity). Value med for Pay Attention, effort med.
7. Render ETA guard + fail-loud (renderEtaGuard.ts, maxRenderMs, RenderQualityError): project total time early, abort over budget; stop on audio/script failure. Before an 8 h 4K. Value low-med, effort low.
8. Static dedup with anchor verification (HF_STATIC_DEDUP): covered by kinetograph item 7; adds PSNR spot-checks of reused frames vs fresh captures.
9. True peak on delivered AAC (render/audioTruePeak.ts, measure only, no limiter): covered by video-director item 1; master_gate.py does it.
10. Field-data PR bodies + weekly changelog digests: covered by scout item 20.
