## 3. Proposed attack for the prompt session (jep, for Idi's ruling)

1. **Read MiniMax's official prompt guide first** (repo README + Comfy doc `docs.comfy.org/tutorials/audio/minimax/minimax-music-3`): exact section names, length limit, whether per-section directions are allowed in lyric tags (e.g. `[Chorus - grand, full choir]`), how it treats parentheses and stretched spellings.
2. Draft the caption box by box (table above), one row per knob, Idi rules row by row (options + recommendation each).
3. Encode notes 2-6 where MiniMax actually reads them:
   - **Sing, not rap** → Vocal Style: "melodic sung pop vocal, legato, sustained vowels; no rapping, no spoken delivery except the [Spoken] parts".
   - **Algae** → spell as sung: test "al-jee", "AL-jee", "algee" (G21 says hyphens work; capitals hurt in ACE-Step, untested in MiniMax). Check with `errmap.py` + Idi's ear.
   - **Grand final chorus** → section tag + caption progression: "final chorus: key-change lift or bigger arrangement, choir, full drums, highest energy of the song".
   - **Melisma only on chosen words** → stretched spelling only on "tune" (and maybe final "you"), keep normal spelling everywhere else; caption: "ornamentation reserved for the word 'tune'".
   - **Keep 974's virtues** → "tomorrow" held into "Every"; `[Instrumental]` break after "borrow" and after the bridge's "turn" (G23).
4. Batch 6-8 seeds per prompt version, score with the toolchain (section 4), Idi listens to the top 3.
5. Lock the song → full one-shot video (G18), which reuses the proof's renderer.
