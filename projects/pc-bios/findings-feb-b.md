## Deliberate changes from Auto or default (cross-photo)

- Intel Default Settings = Performance (a chosen profile; Intel's 0x129-era Performance profile means PL1/PL2 253 W and IccMax 307 A, medium confidence on exact numbers).
- Turbo Power Limits = Enabled with PL1 = 180 W and PL2 = 180 W typed in. Both are below the Performance profile's 253 W, so this is a manual power cap. Clearest hand-set value in the batch.
- Extreme Memory Profile = XMP 1 (DDR5-6000 36-38-38-80-1.350), an explicit profile choice; the fallback when instability is suspected is Disabled (JEDEC 4800 or 5600).
- DDR5 XMP Booster = Disabled, High Bandwidth = Enabled, Low Latency = Enabled. High Bandwidth and Low Latency read Enabled rather than Auto; on Gigabyte Z790 they usually default to Auto, so they may have been toggled (low confidence).
- Intel(R) Dynamic Tuning Technology = Disabled and Legacy Game Compatibility Mode = Enabled. Both may be board defaults; low confidence either was hand-changed.
- CPU Cores Enabling Mode = Random Mode. Board default, no change.
- Everything visible in CPU/PCH Voltage Control and DRAM Voltage Control = Auto. No manual Vcore, no offset. LLC (Load-Line Calibration) sits under Advanced Voltage Settings, not photographed. Core Current Limit (IccMax) = Auto.
- Not visible in this batch: BIOS version, microcode version, LLC, DRAM Voltage / VDD / VDDQ / VPP rows, AVX offset values, C-State details, any stress-test results.
