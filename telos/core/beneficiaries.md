## Checkpoint Protocol

Before starting any project, answer:

| Question | Acceptable Answer | If No Answer |
|----------|-------------------|--------------|
| **Who does this serve?** | Name from hierarchy | Project is vanity |
| **What do they get?** | Concrete deliverable | Project is abstract |
| **When do they get it?** | Date or milestone | Project is indefinite |

**If any answer is missing → do not start.**
