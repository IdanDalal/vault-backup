## Goal Success Pattern (Compounding Engineering)

From PDAC Loop: **Never do the same task twice.**

```
PLAN    → Define clear success criteria
DELEGATE → Hand to agent/tool/collaborator
ASSESS  → Evaluate against criteria
CODIFY  → Extract reusable patterns
```

**Applied to goals:** Each completed goal should produce:
1. The outcome itself
2. A reusable pattern for similar goals
3. Updated TELOS files reflecting new capacity

## Goal Design Template (New)

Before committing to a goal, answer:

1. **What is the forcing function?** (External signal that makes progress inevitable)
2. **What is the minimum viable outcome?** (First "done" checkpoint)
3. **Who will know if I don't do it?** (Accountability human)
4. **What pattern will this codify?** (Compounding value)
5. **VVR check:** Does this build Vision, align with Values, strengthen Reputation?

If any answer is blank → redesign before starting.
